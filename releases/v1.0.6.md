# Postcap v1.0.6

Postcap can now keep itself up to date with Sparkle.

## What's new

- Added a native **Check for Updates…** command to the Postcap menu
- Added an automatic update-check setting
- Added signed Sparkle update metadata to the release pipeline

## Details

This is the first release that uses Sparkle, so it must be installed manually. Future releases can be installed from inside Postcap.
