# Postcap v1.0.5

we are so back

## What's New

- Speed adjustment: exports can be sped up or slowed down while preserving audio pitch
- Output resizing: independent from the crop region
- Playhead in the timeline under the preview
- Trim points are now settable and revisitable directly from player controls
- Haptic feedback on scrubbing and other actions
- Keyboard shortcuts: `I`/`O` to set trim in/out, `Shift-I`/`Shift-O` to jump to them

## Details

- Output resizing uses Lanczos scaling
- The speed field accepts values beyond the slider's common `0.25x-4x` range, you can set it to any number
- Haptic feedback is enabled by default and can be disabled in settings
